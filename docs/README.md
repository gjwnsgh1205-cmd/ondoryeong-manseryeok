# 온도령(溫道令) — 만세력 마음 상담소

**바로 사용: https://gjwnsgh1205-cmd.github.io/ondoryeong-manseryeok/**

설치도 로그인도 없다. 링크를 열면 바로 쓴다. 계산은 전부 브라우저 안에서 일어나고,
생년월일은 어디로도 전송되지 않는다.


만세력(사주 명식) 계산에 심리·생애주기 상담의 언어를 결합한 로컬 웹앱.
**온도령**이라는 젊은 사주 도령 캐릭터가 화면 단계마다 등장해 풀이를 이끈다.
생년월일시를 입력하면 사주팔자를 세우고, 일간 심리 프로필 · 오행 균형 마음 케어 ·
대운 생애주기 상담 · 주제별(마음/관계/일/활력) 상담 카드를 제공한다.

## 실행

정적 파일이므로 아무 웹서버로 열면 된다.

```bash
python -m http.server 8777
```

→ http://localhost:8777/index.html

## 배포

저장소 루트를 그대로 서빙하면 생성 원본(`assets/_master`, 약 9MB)과 도구까지 공개된다.
배포본은 따로 만든다.

```bash
python tools/build.py
```

`docs/`에 HTML/CSS/JS와 `assets/web`, `assets/video`만 담긴다 (약 1.7MB).
GitHub Pages 소스를 **main 브랜치 `/docs`** 로 잡으면 그대로 서비스된다.

### 파일 하나로 보내기

링크 대신 파일째 건네야 할 때가 있다. 이미지·영상까지 전부 인라인한 단일 HTML을 만든다.

```bash
python tools/build_single.py
```

`dist/share/온도령-만세력-상담소.html` (약 1.3MB). 외부 요청이 0건이라 오프라인에서도,
메신저로 받은 파일을 더블클릭해도 그대로 돌아간다. 첫 화면은 0.66MB만 읽고 그려지고,
영상은 그 뒤에 붙는다.

## 캐릭터 — 온도령

젊은 조선 선비 차림의 사주 도령. 화면 단계마다 컷이 바뀐다.

| 자리 | 컷 | 연출 |
|---|---|---|
| 입력 화면 | `idle` (루프) | 책을 든 채 숨 쉬고 눈을 깜빡이며 맞이함 |
| 풀이 로딩 | `reading` (루프) | 책장을 넘기며 골똘히 읽음 |
| 결과 공개 | `reveal` (1회) | 고개를 들어 미소, 손바닥 위에 금빛이 피어남 |
| 맺음말 | `bow` (1회) | 두 손 모아 읍하며 배웅 |

말투는 옛스러운 하게체("~하시게", "~라네")이고, 상담 본문은 존댓말을 유지한다.
도령이 책을 풀어 읽어주는 프레임이라 층위를 다르게 두었다.

mp4에는 알파 채널이 없어 CSS 마스크로 가장자리를 페이지 배경에 녹인다.
mp4가 없거나 `prefers-reduced-motion`이면 같은 자리의 PNG(poster)가 그대로 보인다.

### 에셋 재생성

```bash
pip install -r tools/requirements.txt
```

```bash
python tools/prep_assets.py      # 마젠타 크로마키 제거 + 트림 + i2v 입력 프레임 합성
```

```bash
python tools/optimize_media.py   # mp4 재인코딩(faststart) + poster 추출 + PNG 양자화 (ffmpeg·ffprobe 필요)
```

이미지는 codex CLI 내장 `image_gen`(gpt-image-2), 영상은 BBANANA MCP(Seedance 2.0 i2v)로 만들었다.
캐릭터 일관성은 첫 컷을 레퍼런스로 고정하고 "관절 회전만 변경" 규칙을 프롬프트에 박아 유지했다.

## 계산 규칙 (명시적 선택)

- **절기**: astronomy-engine `SearchSunLongitude` (오차 수 초 수준, KASI 공표값과 ±1분 이내 검증).
  라이브러리 로드 실패 시 Meeus 근사 + ΔT 보정 폴백(±15분).
- **연주/월주**: 입춘·12절 절입 **절대 시각(UTC)** 과 출생 절대 시각을 비교. 경도 보정은 여기에 적용하지 않는다.
- **일주/시주**: 벽시계 → 표준시 이력 반영 → 경도 보정(동경 127.5°, −30분, 균시차 미적용) 후
  23:00(자시)부터 다음 날 일주로 취급.
- **표준시 이력**: 1912 이전 +8:30 근사 / 1954-03-21~1961-08-09 +8:30 /
  서머타임 1948–60(자정 전환), 1987–88(02:00/03:00 전환, 중복 시간대는 표준시 해석).
- **대운수**: 절입까지 일수 ÷ 3, 년·개월 보존(0세 허용).
- **오행 분포**: 간이 가중 — 천간 1.0, 지지 합계 1.0(본기 0.7 + 나머지 지장간 0.3 균등).
- **경계 안전판**: 절기 경계 30분 이내 출생이면 UI에 경고. 시간 미상은 정오 가정 + 절입일 경고.
- 지원 범위: **1900–2050년 양력**. 음력 생일은 양력 변환 후 입력.

## 상담 콘텐츠 원칙

- 단정이 아니라 경향의 언어("~하는 편", "~하곤 해요").
- 의학·심리 진단 금지. 신체 증상 관련 표현은 생활 습관 제안으로 한정하고 병원 안내를 병기.
- 하단 고정 안내: 자살예방 상담전화 **109** · 정신건강 위기상담 **1577-0199**.
