# 결(結) — 만세력 마음 상담소

만세력(사주 명식) 계산에 심리·생애주기 상담의 언어를 결합한 로컬 웹앱.
생년월일시를 입력하면 사주팔자를 세우고, 일간 심리 프로필 · 오행 균형 마음 케어 ·
대운 생애주기 상담 · 주제별(마음/관계/일/활력) 상담 카드를 제공한다.

## 실행

정적 파일이므로 아무 웹서버로 열면 된다.

```bash
python -m http.server 8777
# → http://localhost:8777/index.html
```

## 구조

| 파일 | 역할 |
|---|---|
| `index.html` | 단일 페이지 UI (입력 → 명식 → 상담 리포트) |
| `css/style.css` | 먹색+한지+오방색 테마 |
| `js/manseryeok.js` | 만세력 엔진 — 절기, 사주팔자, 지장간, 십성, 오행, 대운 |
| `js/counsel.js` | 상담 콘텐츠 DB — 일간 프로필, 오행 심리, 십성/대운 상담, 고민별 카드 |
| `js/app.js` | 입력 검증·렌더링 |
| `js/vendor/astronomy.browser.min.js` | astronomy-engine (MIT) — 태양 황경 정밀 계산 |

## 계산 규칙 (명시적 선택)

- **절기**: astronomy-engine `SearchSunLongitude` (오차 수 초 수준, KASI 공표값과 ±1분 이내 검증).
  라이브러리 로드 실패 시 Meeus 근사 + ΔT 보정 폴백(±15분).
- **연주/월주**: 입춘·12절 절입 **절대 시각(UTC)** 과 출생 절대 시각을 비교. 경도 보정은 여기에 적용하지 않는다.
- **일주/시주**: 벽시계 → 표준시 이력 반영 → 경도 보정(동경 127.5°, −30분, 균시차 미적용) 후
  23:00(자시)부터 다음 날 일주로 취급.
- **표준시 이력**: 1912 이전 +8:30 근사 / 1954-03-21~1961-08-09 +8:30 /
  서머타임 1948–60(자정 전환), 1987–88(02:00/03:00 전환, 중복 시간대는 표준시 해석).
- **대운수**: 절입까지 일수 ÷ 3, 년·개월 보존(0세 허용).
- **오행 분포**: 간이 가중 — 천간 1.0, 지지 합계 1.0(본기 0.7 + 나머지 지장간 0.3 균등).
- **경계 안전판**: 절기 경계 30분 이내 출생이면 UI에 경고. 시간 미상은 정오 가정 + 절입일 경고.
- 지원 범위: **1900–2050년 양력**. 음력 생일은 양력 변환 후 입력.

## 상담 콘텐츠 원칙

- 단정이 아니라 경향의 언어("~하는 편", "~하곤 해요").
- 의학·심리 진단 금지. 신체 증상 관련 표현은 생활 습관 제안으로 한정하고 병원 안내를 병기.
- 하단 고정 안내: 자살예방 상담전화 **109** · 정신건강 위기상담 **1577-0199**.
